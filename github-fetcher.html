GitHub commit extractor

Fetch commits for a specific author, repo, and date range — runs entirely in your browser.

Authentication

Generate at github.com → Settings → Developer Settings → Personal Access Tokens (classic). Needs repo scope for private repos, or public_repo for public ones. Your token is never sent anywhere except directly to the GitHub API.
